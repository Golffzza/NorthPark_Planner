# ฐานความรู้สำหรับ AI: อุทยานแห่งชาติแม่วงก์

> **ขอบเขต:** ไฟล์นี้เป็นฐานความรู้ RAG สำหรับ NorthPark Planner เน้นข้อเท็จจริงที่ใช้วางแผนและแนะนำการเที่ยว ไม่ใช่แหล่งยืนยันข้อมูลสด  
> **กฎ freshness:** เวลาเปิด ค่าธรรมเนียม สถานะถนน/เส้นทาง จุดปิดชั่วคราว สภาพอากาศ คุณภาพอากาศ ดอกไม้บาน ที่พักว่าง การจอง และมาตรการรถ **ต้องตรวจข้อมูลปัจจุบันก่อนตอบ**

## 1. สรุปสำหรับนักท่องเที่ยว

แม่วงก์เป็นอุทยานผืนป่าตะวันตกที่เด่นด้านป่าขนาดใหญ่ จุดชมวิวภูเขา แคมป์ และเส้นทางเดินป่าระยะไกล ความยากมีตั้งแต่เที่ยวจุดชมวิวด้วยรถไปจนถึงเส้นทางโมโกจูที่ต้องเตรียมตัวสูงและใช้เจ้าหน้าที่/ระบบอนุญาตตามรอบ

## 2. ข้อมูลพื้นฐานสำหรับ RAG

- **ชื่อไทย:** อุทยานแห่งชาติแม่วงก์
- **ชื่ออังกฤษ:** Mae Wong National Park
- **จังหวัด/พื้นที่เกี่ยวข้องที่ใช้เป็น metadata:** กำแพงเพชร, นครสวรรค์

- **ข้อมูลที่ไม่เชื่อจาก seed โดยอัตโนมัติ:** ค่าเข้า เวลาเปิด พิกัด/อำเภอที่ขัดกับแหล่งทางการ และข้อความ fallback ที่สร้างจาก tags

## 3. Metadata สำหรับระบบแนะนำ

- **tags:** `forest`, `viewpoint`, `camping`, `wildlife`, `trekking`, `remote`
- **low_or_lower_effort_candidates:** ช่องเย็น, กิ่วกระทิง
- **high_effort_candidates:** ยอดเขาโมโกจู
- **best_for:**
- สายป่า ดูนก แคมป์ และวิวภูเขา
- นักเดินป่าประสบการณ์สูงที่ต้องการทริประยะไกล
- **avoid_or_verify_when:**
- ผู้ไม่พร้อมเดินระยะไกลเลือกโมโกจู
- ใช้ข้อมูลเก่าของรอบเปิดเส้นทางเป็นสถานะปัจจุบัน
- **inference rule:** Chatbot สามารถ “อนุมานคำแนะนำ” จาก walking + difficulty + access + risks ได้ แต่ต้องพูดเป็นเหตุผล เช่น “ดูเหมาะกว่าเพราะเดินสั้นกว่า” ไม่ใช่เปลี่ยน inference เป็นข้อเท็จจริงด้าน accessibility
- **accessibility rule:** หากไม่มีข้อมูลทางลาด รถเข็น บันได ห้องน้ำผู้พิการ หรือระยะพื้นต่างระดับ ห้ามประกาศว่า wheelchair-friendly / elderly-friendly แบบเด็ดขาด

## 4. สถานที่ท่องเที่ยวและกิจกรรม

### A01 — ช่องเย็น

- **type:** `VIEWPOINT`
- **summary:** พื้นที่สูงและลานพัก/กางเต็นท์ที่มีอากาศเย็นและมุมมองผืนป่า เหมาะกับดูนกและสัมผัสป่าดิบเขา
- **walking:** สั้นในบริเวณจุดบริการ
- **difficulty:** `LOW`
- **typical_duration:** 1-3 ชั่วโมงหรือพักค้างคืน
- **access:** ขับรถตามเส้นทางอุทยานเมื่อเปิด ต้องตรวจเวลาเข้าออก/ข้อจำกัดรถ
- **best_season_or_condition:** ตลอดปีเมื่อพื้นที่เปิดและสภาพอากาศเหมาะสม
- **suitable_for:** พิจารณาจากระดับการเดิน ความยาก และความเสี่ยง
- **risks:** หมอก / ถนนภูเขา / สัตว์ป่า
- **source_ids:** S01
- **retrieval_hint:** เมื่อผู้ใช้ถามหา `viewpoint` หรือกล่าวถึง “ช่องเย็น” ให้ retrieval พยายามดึง chunk นี้ก่อน และอย่าสรุปสถานะเปิด-ปิดจากข้อความ static นี้

### A02 — กิ่วกระทิง

- **type:** `VIEWPOINT`
- **summary:** จุดชมวิวทิวเขาและผืนป่าระหว่างเส้นทางขึ้นพื้นที่สูง
- **walking:** สั้นถึงปานกลาง
- **difficulty:** `LOW-MODERATE`
- **typical_duration:** 30-60 นาที
- **access:** ตามเส้นทางรถเมื่อจุดเปิด
- **best_season_or_condition:** ตลอดปีเมื่อพื้นที่เปิดและสภาพอากาศเหมาะสม
- **suitable_for:** พิจารณาจากระดับการเดิน ความยาก และความเสี่ยง
- **risks:** หน้าผา / ลมแรง / หมอก
- **source_ids:** S01
- **retrieval_hint:** เมื่อผู้ใช้ถามหา `viewpoint` หรือกล่าวถึง “กิ่วกระทิง” ให้ retrieval พยายามดึง chunk นี้ก่อน และอย่าสรุปสถานะเปิด-ปิดจากข้อความ static นี้

### A03 — ยอดเขาโมโกจู

- **type:** `TRAIL`
- **summary:** เส้นทางเดินป่าระยะไกลสู่ยอดเขาสูง เป็นกิจกรรมแบบ expedition มากกว่าทริปเดินเล่นทั่วไป
- **walking:** หลายสิบกิโลเมตรรวมไป-กลับ ขึ้นกับเส้นทางที่อุทยานกำหนด
- **difficulty:** `VERY_HIGH`
- **typical_duration:** หลายวัน
- **access:** ต้องใช้ระบบอนุญาต/รอบกิจกรรมและเจ้าหน้าที่ตามกติกาปัจจุบัน
- **best_season_or_condition:** เปิดเป็นฤดูกาลเมื่ออุทยานประกาศ
- **suitable_for:** นักเดินป่าที่มีประสบการณ์และสมรรถภาพดี
- **risks:** เหนื่อยล้าสูง / อากาศเปลี่ยนเร็ว / พื้นที่ห่างไกล / สัตว์ป่า
- **source_ids:** S01, S02
- **retrieval_hint:** เมื่อผู้ใช้ถามหา `trail` หรือกล่าวถึง “ยอดเขาโมโกจู” ให้ retrieval พยายามดึง chunk นี้ก่อน และอย่าสรุปสถานะเปิด-ปิดจากข้อความ static นี้

## 8. ฤดูกาลและสภาพแวดล้อม

- ฤดูกาลที่เหมาะสมต่างกันตาม attraction และสภาพอากาศจริง
- สถานะเปิด-ปิดตามฤดูกาลต้องตรวจสดก่อนตอบ

**Seasonality policy**
- “ฤดูที่มักเหมาะ” ไม่เท่ากับ “วันนี้เหมาะ”
- ทะเลหมอก ดอกไม้ ปริมาณน้ำตก และทัศนวิสัยขึ้นกับสภาพอากาศจริง
- ช่วงไฟป่า/PM2.5 ต้องใช้ข้อมูลคุณภาพอากาศหรือประกาศสดก่อนแนะนำ

## 9. ความปลอดภัยและข้อควรระวัง

- พื้นที่เป็นถิ่นอาศัยสัตว์ป่า ต้องไม่ให้อาหารหรือเข้าใกล้
- ถนนขึ้นเขาควรใช้ความเร็วต่ำและเผื่อเบรก
- เส้นทางโมโกจูห้ามประเมินความยากต่ำกว่าความจริง
- เคารพป้ายและคำสั่งเจ้าหน้าที่ทุกกรณี
- ไม่ให้อาหารสัตว์ป่า ไม่เก็บพืช หิน หรือทรัพยากรกลับ
- ถ้าผู้ใช้ถามเรื่องความปลอดภัย “วันนี้” ให้เชื่อม Weather/Warning/Current-status tools แทนการตอบจาก RAG เพียงอย่างเดียว

- **suitable_for:** สายป่า ดูนก แคมป์ และวิวภูเขา, นักเดินป่าประสบการณ์สูงที่ต้องการทริประยะไกล
- **source_ids:** S01, S02

## 12. Q&A สำหรับทดสอบระบบ (DO_NOT_EMBED)

### Q01 — จุดเด่นของ อุทยานแห่งชาติแม่วงก์ คืออะไร
ใช้ `## 1`, `## 3` และ `## 4` เพื่อสรุปตามความสนใจของผู้ใช้ ไม่ต้องท่องทุก attraction

### Q02 — ถ้าไม่อยากเดินเยอะควรเริ่มดูจุดไหน
เริ่มพิจารณา **ช่องเย็น** จาก difficulty/walking ที่เก็บไว้ แล้วตรวจข้อจำกัดการเข้าถึงจริงก่อนแนะนำ

### Q03 — จุดไหนใช้แรงมากที่สุด
ในข้อมูลชุดนี้ตัวเลือกที่ใช้แรงสูงคือ **ยอดเขาโมโกจู** แต่ต้องอ่าน field `difficulty`, `walking`, `risks` และสถานะปัจจุบันร่วมกัน

### Q04 — เดือนไหนเหมาะที่สุด
อย่าตอบเป็นเดือนเดียวแบบตายตัว ให้อ้าง `## 8` และ attraction field `best_season_or_condition` พร้อมบอกว่าฝน ดอกไม้ หมอก น้ำตก และไฟป่าเป็น seasonal

### Q05 — ถ้าพาเด็ก ผู้สูงอายุ หรือคนมีข้อจำกัดการเดินไปได้ไหม
ห้าม infer จากคำว่า “ง่าย” อย่างเดียว ให้แยก walking distance, stairs/slope, road access, toilet/parking และข้อจำกัดสุขภาพ หากไม่มีหลักฐาน accessibility ให้ตอบว่า “ยังยืนยันไม่ได้”

### Q06 — วันนี้อุทยานเปิดไหม ค่าเข้าเท่าไร
ห้ามตอบจากไฟล์ static นี้ ต้องใช้ข้อมูลสดจากกรมอุทยานฯ/หน่วยพื้นที่ หรือ tool ที่เชื่อมข้อมูลปัจจุบัน

### Source handling
- `สูง` = หน่วยงานรัฐเจ้าของข้อมูล/กรมอุทยานฯ
