# ฐานความรู้สำหรับ AI: อุทยานแห่งชาติห้วยน้ำดัง

> **ขอบเขต:** ไฟล์นี้เป็นฐานความรู้ RAG สำหรับ NorthPark Planner เน้นข้อเท็จจริงที่ใช้วางแผนและแนะนำการเที่ยว ไม่ใช่แหล่งยืนยันข้อมูลสด
> **กฎ freshness:** เวลาเปิด ค่าธรรมเนียม สถานะถนน/เส้นทาง จุดปิดชั่วคราว สภาพอากาศ คุณภาพอากาศ ดอกไม้บาน ที่พักว่าง การจอง และมาตรการรถ **ต้องตรวจข้อมูลปัจจุบันก่อนตอบ**

## 1. สรุปสำหรับนักท่องเที่ยว

ห้วยน้ำดังขึ้นชื่อเรื่องทะเลหมอก จุดชมวิวดอยกิ่วลม แคมป์ และน้ำพุร้อนโป่งเดือด พื้นที่มีทั้งจุดชมวิวที่เดินน้อยและกิจกรรมธรรมชาติที่ใช้เวลามากขึ้น จึงเหมาะกับผู้ชอบอากาศเย็นและวิวภูเขา

- **จังหวัด/พื้นที่เกี่ยวข้องที่ใช้เป็น metadata:** เชียงใหม่, แม่ฮ่องสอน

- **ข้อมูลที่ไม่เชื่อจาก seed โดยอัตโนมัติ:** ค่าเข้า เวลาเปิด พิกัด/อำเภอที่ขัดกับแหล่งทางการ และข้อความ fallback ที่สร้างจาก tags
- **หลักการตอบ:** ถ้าข้อเท็จจริงในไฟล์นี้กับประกาศสดขัดกัน ให้ประกาศสดของ DNP/หน่วยพื้นที่มีน้ำหนักสูงกว่า

## 3. Metadata สำหรับระบบแนะนำ

- **tags:** `viewpoint`, `sea-of-mist`, `camping`, `hot-spring`, `mountain`, `photography`
- **low_or_lower_effort_candidates:** จุดชมวิวดอยกิ่วลม, ลานกางเต็นท์ห้วยน้ำดัง, โป่งเดือดป่าแป๋
- **high_effort_candidates:** ไม่มีจุด HIGH/VERY_HIGH ในรายการหลักชุดนี้
- **best_for:**
- ผู้เดินน้อยที่ชอบวิว
- สายแคมป์
- ครอบครัวที่เที่ยวเฉพาะโซนบริการ
- คู่รัก/ช่างภาพ
- **avoid_or_verify_when:**
- รับประกันทะเลหมอก
- ขับรถเร็วในช่วงเช้ามืดหรือหมอกจัด
- **inference rule:** Chatbot สามารถ “อนุมานคำแนะนำ” จาก walking + difficulty + access + risks ได้ แต่ต้องพูดเป็นเหตุผล เช่น “ดูเหมาะกว่าเพราะเดินสั้นกว่า” ไม่ใช่เปลี่ยน inference เป็นข้อเท็จจริงด้าน accessibility
- **accessibility rule:** หากไม่มีข้อมูลทางลาด รถเข็น บันได ห้องน้ำผู้พิการ หรือระยะพื้นต่างระดับ ห้ามประกาศว่า wheelchair-friendly / elderly-friendly แบบเด็ดขาด

## 4. สถานที่ท่องเที่ยวและกิจกรรม

### A01 — จุดชมวิวดอยกิ่วลม

- **type:** `VIEWPOINT`
- **summary:** จุดชมทะเลหมอกและพระอาทิตย์ขึ้นที่เป็นภาพจำของห้วยน้ำดัง
- **walking:** สั้นจากบริเวณจอด/ลานบริการ
- **difficulty:** `LOW`
- **typical_duration:** 30-90 นาที
- **access:** รถถึงบริเวณจุดชมวิวเมื่อพื้นที่เปิด
- **best_season_or_condition:** ฤดูหนาวและหลังฝนมีโอกาสเห็นทะเลหมอก แต่ขึ้นกับอากาศจริง
- **suitable_for:** ผู้เดินน้อย / ครอบครัว / ช่างภาพ
- **risks:** หมอกหนา / ลมแรง / อากาศหนาว
- **source_ids:** S01
- **retrieval_hint:** เมื่อผู้ใช้ถามหา `viewpoint` หรือกล่าวถึง “จุดชมวิวดอยกิ่วลม” ให้ retrieval พยายามดึง chunk นี้ก่อน และอย่าสรุปสถานะเปิด-ปิดจากข้อความ static นี้

### A02 — ลานกางเต็นท์ห้วยน้ำดัง

- **type:** `CAMPSITE`
- **summary:** พื้นที่พักค้างคืนใกล้จุดชมวิว เหมาะกับการดูดาวและตื่นชมทะเลหมอก
- **walking:** สั้นในบริเวณ
- **difficulty:** `LOW`
- **typical_duration:** พักค้างคืน
- **access:** ตรวจการจองและความพร้อมลานล่าสุด
- **best_season_or_condition:** ตลอดปีเมื่อพื้นที่เปิดและสภาพอากาศเหมาะสม
- **suitable_for:** พิจารณาจากระดับการเดิน ความยาก และความเสี่ยง
- **risks:** อากาศหนาว / ลมแรง / คนหนาแน่นช่วงพีก
- **source_ids:** S01
- **retrieval_hint:** เมื่อผู้ใช้ถามหา `campsite` หรือกล่าวถึง “ลานกางเต็นท์ห้วยน้ำดัง” ให้ retrieval พยายามดึง chunk นี้ก่อน และอย่าสรุปสถานะเปิด-ปิดจากข้อความ static นี้

### A03 — โป่งเดือดป่าแป๋

- **type:** `HOT_SPRING`
- **summary:** แหล่งน้ำพุร้อนธรรมชาติในพื้นที่อุทยาน มีทางเดินศึกษาธรรมชาติและปรากฏการณ์น้ำร้อน
- **walking:** ปานกลางตามเส้นทางชม
- **difficulty:** `LOW-MODERATE`
- **typical_duration:** 1-2 ชั่วโมง
- **access:** เข้าทางพื้นที่โป่งเดือดและเดินตามทางที่จัดไว้
- **best_season_or_condition:** ตลอดปีเมื่อพื้นที่เปิดและสภาพอากาศเหมาะสม
- **suitable_for:** พิจารณาจากระดับการเดิน ความยาก และความเสี่ยง
- **risks:** น้ำร้อน / พื้นเปียก / ไอน้ำ
- **source_ids:** S01
- **retrieval_hint:** เมื่อผู้ใช้ถามหา `hot_spring` หรือกล่าวถึง “โป่งเดือดป่าแป๋” ให้ retrieval พยายามดึง chunk นี้ก่อน และอย่าสรุปสถานะเปิด-ปิดจากข้อความ static นี้

## 8. ฤดูกาลและสภาพแวดล้อม

- ทะเลหมอกเป็นปรากฏการณ์อากาศ ไม่รับประกันว่าจะเห็น
- มีมาตรการไฟป่าตามฤดูกาล ต้องตรวจประกาศ

**Seasonality policy**
- “ฤดูที่มักเหมาะ” ไม่เท่ากับ “วันนี้เหมาะ”
- ทะเลหมอก ดอกไม้ ปริมาณน้ำตก และทัศนวิสัยขึ้นกับสภาพอากาศจริง
- ช่วงไฟป่า/PM2.5 ต้องใช้ข้อมูลคุณภาพอากาศหรือประกาศสดก่อนแนะนำ

## 9. ความปลอดภัยและข้อควรระวัง

- หมอกลดทัศนวิสัยบนถนน
- อากาศกลางคืนหนาว
- น้ำพุร้อนห้ามสัมผัสบริเวณอุณหภูมิสูง
- ช่วงไฟป่า/หมอกควันอาจมีมาตรการเฉพาะ
- เคารพป้ายและคำสั่งเจ้าหน้าที่ทุกกรณี
- ไม่ให้อาหารสัตว์ป่า ไม่เก็บพืช หิน หรือทรัพยากรกลับ
- ถ้าผู้ใช้ถามเรื่องความปลอดภัย “วันนี้” ให้เชื่อม Weather/Warning/Current-status tools แทนการตอบจาก RAG เพียงอย่างเดียว

## 10. แผนเที่ยวตัวอย่าง

### Trip style summary

- **day_trip:** CONDITIONAL — มีทั้งจุดที่ทำเป็นทริปวันเดียวได้และจุดที่ควรวางแผนพักค้าง ขึ้นกับ attraction
- **overnight:** RECOMMENDED สำหรับบางเส้นทาง/กิจกรรมที่ข้อมูลเดิมระบุเรื่องพักค้าง; ไม่ใช่ข้อบังคับสำหรับทั้งอุทยาน
- **typical_duration:** จุดชมวิวดอยกิ่วลม: 30-90 นาที | ลานกางเต็นท์ห้วยน้ำดัง: พักค้างคืน | โป่งเดือดป่าแป๋: 1-2 ชั่วโมง
- **best_time_of_day:** จุดชมวิวดอยกิ่วลม: ฤดูหนาวและหลังฝนมีโอกาสเห็นทะเลหมอก แต่ขึ้นกับอากาศจริง | ลานกางเต็นท์ห้วยน้ำดัง: ตลอดปีเมื่อพื้นที่เปิดและสภาพอากาศเหมาะสม
- **pace:** เบา/เวลาจำกัด, สมดุล 1 วัน
- **suitable_for:** ผู้เดินน้อยที่ชอบวิว, สายแคมป์, ครอบครัวที่เที่ยวเฉพาะโซนบริการ, คู่รัก/ช่างภาพ
- **source_ids:** S01

- **เหมาะกับ:** ผู้เดินได้ระดับทั่วไปและมีเวลาประมาณหนึ่งวัน
- **ข้อจำกัด:** ต้องใช้ route จริงจากพิกัด attraction และสถานะถนน/จุดเปิด ไม่ใช่เรียงตามข้อความนี้อย่างเดียว


> แผนเหล่านี้เป็น template เชิงตรรกะ ไม่ใช่ itinerary ที่รับประกันว่าเปิดครบทุกจุดในวันเดินทาง ต้องใช้ route, opening status, weather และเวลาพระอาทิตย์ตกจริงประกอบ

## 12. Q&A สำหรับทดสอบระบบ (DO_NOT_EMBED)

### Q01 — จุดเด่นของ อุทยานแห่งชาติห้วยน้ำดัง คืออะไร
ใช้ `## 1`, `## 3` และ `## 4` เพื่อสรุปตามความสนใจของผู้ใช้ ไม่ต้องท่องทุก attraction

### Q02 — ถ้าไม่อยากเดินเยอะควรเริ่มดูจุดไหน
เริ่มพิจารณา **จุดชมวิวดอยกิ่วลม** จาก difficulty/walking ที่เก็บไว้ แล้วตรวจข้อจำกัดการเข้าถึงจริงก่อนแนะนำ

### Q03 — จุดไหนใช้แรงมากที่สุด
ในข้อมูลชุดนี้ตัวเลือกที่ใช้แรงสูงคือ **โป่งเดือดป่าแป๋** แต่ต้องอ่าน field `difficulty`, `walking`, `risks` และสถานะปัจจุบันร่วมกัน

### Q04 — เดือนไหนเหมาะที่สุด
อย่าตอบเป็นเดือนเดียวแบบตายตัว ให้อ้าง `## 8` และ attraction field `best_season_or_condition` พร้อมบอกว่าฝน ดอกไม้ หมอก น้ำตก และไฟป่าเป็น seasonal

### Q05 — ถ้าพาเด็ก ผู้สูงอายุ หรือคนมีข้อจำกัดการเดินไปได้ไหม
ห้าม infer จากคำว่า “ง่าย” อย่างเดียว ให้แยก walking distance, stairs/slope, road access, toilet/parking และข้อจำกัดสุขภาพ หากไม่มีหลักฐาน accessibility ให้ตอบว่า “ยังยืนยันไม่ได้”

### Q06 — วันนี้อุทยานเปิดไหม ค่าเข้าเท่าไร
ห้ามตอบจากไฟล์ static นี้ ต้องใช้ข้อมูลสดจากกรมอุทยานฯ/หน่วยพื้นที่ หรือ tool ที่เชื่อมข้อมูลปัจจุบัน

### Source handling
- `สูง` = หน่วยงานรัฐเจ้าของข้อมูล/กรมอุทยานฯ
- `สูง-ปานกลาง` = หน่วยงานรัฐ/การท่องเที่ยวที่เหมาะกับข้อมูล stable แต่ข้อมูลราคา เวลา และสถานะควรตรวจซ้ำ
- URL มีไว้สำหรับ provenance และ live re-check; ไม่ควร embed URL ยาวลง vector
- หาก source ขัดกัน ให้บอกว่าข้อมูลขัดกัน พร้อมวันที่ ไม่เลือกค่าหนึ่งแบบเดา

## 14. กฎเฉพาะสำหรับ Chatbot (DO_NOT_EMBED_POLICY)

- ห้ามคำนวณคะแนน Trip Evaluation เอง คะแนนต้องมาจาก Evaluation Engine ของ NorthPark เท่านั้น
- ห้ามยืนยัน “เปิดวันนี้”, “ค่าเข้าเท่านี้วันนี้”, “ถนนผ่านแน่นอน”, “ดอกกำลังบาน” จาก static RAG
- เมื่อคำถามมี hard constraint เช่น จังหวัด ให้ filter metadata ก่อน vector ranking
- เมื่อผู้ใช้บอก “ไม่อยากเดินเยอะ” ให้ลดอันดับ attraction ที่ `difficulty=HIGH/VERY_HIGH` หรือ walking หลายกิโลเมตร แม้ semantic similarity สูง
- เมื่อผู้ใช้บอกเด็ก/ผู้สูงอายุ/รถเข็น ให้ถามหรือใช้ accessibility evidence; ห้ามเดาจากคำว่า `LOW`
- ให้ตอบอย่างเป็นธรรมชาติและอธิบายเหตุผลการแนะนำจาก evidence ที่ retrieval ได้
- ไม่มี policy พิเศษนอกเหนือจากกฎกลางของ NorthPark RAG

## 15. การตรวจสอบแหล่งข้อมูลทางการ (DO_NOT_EMBED_POLICY)

- **source_audit_at:** 2026-09-30
- **source_audit_status:** `DNP_PRIMARY_PRESENT`

- **other_official_government_domains:** cbtthailand.dasta.or.th
- **scope:** ตรวจ provenance ของข้อมูลกับแหล่งหน่วยงานรัฐที่ระบุในไฟล์ และเพิ่มแหล่ง DNP เมื่อจำเป็น; ไม่ถือว่า field ที่เปลี่ยนตามเวลาได้รับการยืนยันแบบ real-time
