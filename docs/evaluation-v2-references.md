## ทะเบียนที่มาของ Threshold และสมมติฐาน

ประเภท: **1 = จากแหล่งโดยตรง**, **2 = ดัดแปลงจากแหล่ง**, **3 = โครงการกำหนดเอง ต้องตรวจสอบเพิ่ม**

| เกณฑ์/กติกาใน Scoring Spec | ประเภท | คำอธิบายที่ต้องใช้ในวิทยานิพนธ์ |
|---|---:|---|
| TMD 25.1/50.1 mm ใน 1 ชั่วโมง; 35.1/90.1 mm ใน 24 ชั่วโมง | 1 | เป็นเกณฑ์จัดชั้นปริมาณฝน **ตามช่วงเวลาที่ระบุ**; ไม่ใช่คะแนนผลกระทบต่อแผน |
| WMO 2.5/10/50 mm/h | 1 เฉพาะนิยามในเอกสาร | เอกสารระบุ rain intensity ที่วัดช่วงสั้น; ไม่ใช่ผลรวมพยากรณ์หนึ่งชั่วโมง |
| ใช้ 2.5/10 กับ hourly sum เพื่อแบ่ง `L_rain` | 2 | ดัดแปลงจากนิยาม WMO เป็น candidate ของโครงการ; ต้องตรวจสอบกับข้อมูลไทย/ผู้เชี่ยวชาญ |
| NWS 45/58 mph สำหรับ gust advisory/warning ในพื้นที่ที่อ้าง | 1 เฉพาะพื้นที่ NWS นั้น | ไม่ใช่ threshold ไทย |
| Gust `56/72/93 km/h` → L0–L3 | 2 และ 3 | 72/93 ปัดจาก 45/58 mph ของ NWS; 56 เป็นค่าโครงการที่ยังไม่มีเกณฑ์รองรับ; ทั้งชุดต้องยืนยันในบริบทท่องเที่ยวไทย |
| `max(L_rain,L_gust,L_code)`; `Wi=100(1−Li/3)` | 3 | การรวมเพื่อไม่หักซ้ำและการแมปคะแนนเป็นแบบจำลองโครงการ |
| `W=0.40WR+0.60WP`, `S=0.30W+0.20D+0.30T+0.20A` | 3 | น้ำหนักทดลอง; R6 รองรับ *วิธีตรวจความไว* ไม่รองรับตัวเลขน้ำหนัก |
| D linear cutoff `600 นาที` และ piecewise anchors | 3 | 600 และบาง breakpoint ยืมจาก **V1 ภายในโครงการ** เพื่อเป็นฐานทดลอง ไม่ใช่มาตรฐานภายนอก |
| T = สัดส่วน opening window ที่เหลือ | 3 | สูตรเชิงนิยามของโครงการ; ขึ้นกับเวลาเข้าชมที่ยืนยันได้และไม่ใช่เปอร์เซ็นต์ความปลอดภัย |
| A checks และเกณฑ์ PASS/FAIL/UNKNOWN | 3 | วิธีวัดความครบของหลักฐานการเข้าถึงที่โครงการเสนอ; ยังขาดข้อมูลทางเข้า/last mile จริง |
| Severe warning จากรหัส 95/96/97/99 | 2 | ความหมายรหัสจาก Open-Meteo โดยตรง; การตัดสินใจแสดง warning เป็นนโยบายโครงการ |
| `COMPLETE/INCOMPLETE`, `canProceed` แบบ 3 ค่า, rounding half-up | 3 | กฎข้อมูลและการรายงานของโครงการ ไม่ใช่ข้อบังคับจาก ISO 31000 |

## ข้อจำกัดในการอ้างอิง

- TMD ระบุชั้นฝน 1 ชั่วโมงและ 24 ชั่วโมงต่างกัน; เอกสาร WMO ที่อ้างระบุว่าความเข้มฝนใช้ช่วงวัด 3 นาที; Open-Meteo `precipitation` เป็นผลรวมหนึ่งชั่วโมง การเรียกสามอย่างนี้ว่าเกณฑ์เดียวกันจะผิดหน่วยเวลา
- ไม่มีหลักฐานที่ตรวจพบสำหรับความสัมพันธ์เชิงปริมาณระหว่าง gust/rain forecast กับความปลอดภัยของทริปอุทยานเหนือ หรือสำหรับจุดตัด D ที่ 600 นาที จึงต้องใช้คำว่า *candidate/project-defined* จนกว่าจะตรวจสอบ
- หน้า ISO ที่เปิดอ่านได้เป็นบทสรุปมาตรฐาน ไม่ใช่สิทธิอ่านรายละเอียดทั้งฉบับ จึงอ้างเพียงกรอบการจัดการความเสี่ยงตามหน้า ISO
- หลักฐาน forecast และ route provider ไม่ยืนยันสถานะเปิดอุทยาน ถนนเข้าจริง หรือการเดินทางช่วงต่อรถ ข้อมูลเหล่านี้ต้องมีแหล่งเฉพาะก่อนให้ A หรือ blocking decision
